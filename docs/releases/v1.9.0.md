# dietcode-plugin v1.9.0 — Kernel Authority Bridge

**Release date:** 2026-06-09

## One-line summary

Adds optional DietCode kernel authority bridge for coherent patching, verification,
JoyZoning journaling, and gated raw-write interception, with safe defaults and
rollback controls.

## What shipped

The kernel is an **optional authority layer** on macOS. BroccoliDB, JoyZoning,
and governance work without it. Linux installs degrade gracefully.

```text
Phase 1   kernel quarantined
Phase 1.5 workspace boundary
Phase 2A  bridge preflight
Phase 2B  opt-in patch
Phase 2C  receipt journal
Phase 3A  raw write warning
Phase 3B  hard block with fuse
Phase 4   verify loop
Phase 5   operations + failure audit
```

Closed loop:

```text
intent → patch → receipt → journal → verify → verification journal → convergence
```

## Safe defaults

Install seeds:

```yaml
dietcode:
  kernel:
    bridge:
      enabled: true
      mutations_enabled: false
      raw_write_policy: warn
```

Raw writes are hard-blocked only when **both** `raw_write_policy: block` and
`DIETCODE_KERNEL_RAW_WRITE_BLOCK=1` are set and the patch gate is fully open.

## Upgrade notes

- No breaking changes to existing BroccoliDB / JoyZoning / JSDP surfaces.
- Kernel mutation is opt-in via `dietcode.kernel.bridge.mutations_enabled: true`.
- Rollback: set `raw_write_policy: allow`, unset `DIETCODE_KERNEL_RAW_WRITE_BLOCK`,
  optionally close the patch gate.
