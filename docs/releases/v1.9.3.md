# dietcode-plugin v1.9.3 — Kernel Cockpit Responsiveness

**Release date:** 2026-06-09

## One-line summary

Adds live cockpit views, operation states, next-action hints, heartbeat UX, and
responsiveness metrics for long-running kernel bridge operations.

## What shipped

Release-grade operator UX on top of v1.9.2 performance telemetry — no mutation
semantics changes.

| Surface | Command |
| --- | --- |
| One-screen cockpit | `/dietcode kernel cockpit` |
| Live watch | `/dietcode kernel watch` |
| UX perf budgets | `/dietcode kernel perf --ux --last 10` |
| Smoke checks | `python scripts/kernel_cockpit_smoke.py` |

### Cockpit panels

- Current operation (state, phase, elapsed, next phase)
- Workspace root
- Patch gate + raw write policy
- Last error / last successful patch / last verify
- Safe to retry
- Exactly one recommended next action

### Normalized operation states

`idle` · `accepted` · `preparing` · `validating` · `recovering` · `applying` ·
`verifying` · `journaling` · `blocked` · `stalled` · `failed` · `complete`

### UX latency budgets (`perf --ux`)

| Metric | Budget |
| --- | --- |
| Time to acknowledgement | < 100ms |
| Time to first progress | < 500ms |
| Silent window (active op) | < 5s |

## Upgrade notes

- Patch release on v1.9.2 — no config migration required.
- Set `DIETCODE_ASCII_ONLY=1` for plain-ASCII cockpit symbols in constrained terminals.
- All mutation safety gates, receipts, journaling, and verify authority unchanged.
